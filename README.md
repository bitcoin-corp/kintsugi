# Kintsugi

**Get paid in BSV to build and grow bWalletX and its apps.**

Kintsugi (金継ぎ) is mending broken pottery with gold, so the repair shows. It is how The Bitcoin Corporation Ltd fixes and builds its own products, bWalletX, bChatX and the b*X apps, with developers who work AI-first in Claude Code.

- **Pay:** $20 an hour to the developer, paid in BSV (clients pay $25 an hour; $5 is Kintsugi's fee) at that day's rate, up to 8 billable hours a day.
- **Peer to peer:** when the work is accepted, the client pays the developer directly, wallet to wallet. Kintsugi takes a fee as a separate payment and never holds the money.
- **Three signatures:** client, developer and Kintsugi sign one contract in bChatX: task, price, deadline, what counts as done.
- **Joining:** verified ID (Veriff), a paid Claude plan with Claude Code, one entry task, then levels with accepted work.

We are taking names now: [register interest](https://bwalletx.com/kintsugi/program#apply). Overview and the work log so far: [bwalletx.com/kintsugi](https://bwalletx.com/kintsugi).
